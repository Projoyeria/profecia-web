# Profecía — sitio web

Sitio estático listo para publicarse gratis con GitHub Pages.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño responsive y paleta de colores.
- `script.js`: menú móvil y año automático.

## Publicar en GitHub Pages
1. Entra a GitHub y crea un repositorio nuevo, por ejemplo: `profecia-web`.
2. Sube `index.html`, `styles.css` y `script.js` a la raíz del repositorio.
3. En el repositorio ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`.
6. Guarda. GitHub generará una dirección similar a:
   `https://TU-USUARIO.github.io/profecia-web/`

## Antes de publicar
Cambia los botones de WhatsApp e Instagram en `index.html`.
Reemplaza los bloques de muestra de la sección "Colección" por fotografías reales.
